# Tony-Cybersec-Portfolio

## Projects
Navigate to the desired project to learn more about the structure and the learning
objectives. Each project is throughly documented and each step taken is carefully
layed out and explained. Final results are also presented to highlight the project's
significance.

### 🍯 [Azure Sentinel SOC Lab: Honeypot Traffic Analysis & Threat Detection](./projects/azure-soc-honeypot-sentinel)
Deployed and intentionally exposed VM in Azure and forwarded logs from VM into Microsoft Sentinel to 
analyze possible malicious login attempts using KQL

### 🔍 [Azure Vulnerability Management](./projects/azure-vulnerability-management)
Deployed vulnerable VMs (targets) in Azure and used OpenVAS and Nessus to scan for known vulnerabilities to analyze results using CVSS severity scoring.
